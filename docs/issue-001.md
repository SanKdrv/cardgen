# ISSUE-001 — AI-помощник для подготовки товарных описаний

**Тип:** задача · **Приоритет:** высокий · **Оценка:** 2–4 часа (MVP)

## Контекст

B2B-каталог контрольно-измерительных приборов пополняется вручную:
контент-менеджер собирает карточку из паспорта, прайса и переписки с
поставщиком. Нужен прототип, который готовит черновик по структурированным
данным и не добавляет характеристик, которых нет во входе.

## Вход

JSON или веб-форма:

```json
{
  "name": "Манометр показывающий DM 02",
  "manufacturer": "Манотомь",
  "specs": {
    "диапазон измерений": "0–1,6 МПа",
    "класс точности": "1,5",
    "присоединение": "G1/2",
    "диаметр корпуса": "100 мм"
  },
  "description": "Прибор предназначен для измерения избыточного давления…"
}
```

## Выход

- SEO-заголовок до 70 символов;
- SEO-описание 800–1200 символов;
- структурированный список характеристик;
- 3–5 поисковых запросов;
- коммерческий блок для менеджера;
- список отсутствующих полей;
- JSON и Markdown для копирования.

## Функциональные требования

- [x] приём JSON и данных из формы;
- [x] вызов LLM через API;
- [x] генерация всех пяти блоков карточки;
- [x] отдача результата в JSON и Markdown;
- [x] сообщение о недостающих полях;
- [x] обработка ошибок API, пустых полей и некорректного JSON;
- [x] отсутствие выдуманных характеристик: значения только из входа;
- [x] пометка отсутствующих характеристик.

## Нефункциональные требования

- [x] Python 3.11+;
- [x] ключ только через переменные окружения, `.env` в `.gitignore`;
- [x] запуск по README без дополнительных сервисов;
- [x] линтеры и тесты;
- [x] воспроизводимый офлайн-режим для демо.

## Критерии приёмки

1. `pip install -e ".[dev]"` и `uvicorn cardgen.api:app` поднимают сервис.
2. `POST /api/v1/cards` с `examples/request-dm02.json` возвращает 200 и все поля.
3. Для товара без класса точности `missing_fields` содержит это поле.
4. Подмена `1,5` на `2,5` в ответе модели приводит к отклонению и fallback.
5. `pytest` проходит, покрытие не ниже 85%.
6. `ruff check .`, `ruff format --check .`, `mypy src` проходят.
7. В репозитории есть README, примеры результата и описание промптов.

## Вне scope

- CMS, админ-панель, база данных, деплой;
- парсинг PDF и OCR;
- интеграция с 1С;
- векторная база и RAG.
