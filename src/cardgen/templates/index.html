Как это работает

  1. Факты. Сервис собирает числа, единицы и коды из JSON и текста паспорта.
  2. Генерация. LLM пишет тексты, но не получает права добавлять новые факты.
  3. Проверка. Каждое число и обозначение сверяется с исходными данными.
  4. Ретрай или шаблон. При нарушении модель получает замечания; после второй неудачи включается детерминированный шаблон.

Что попадёт в результат

  • SEO-заголовок до 70 символов
  • SEO-описание 800–1200 символов
  • структурированные характеристики
  • 3–5 поисковых запросов
  • коммерческий блок для менеджера
  • список недостающих данных

Если данных мало

Сервис не придумывает значения: отсутствующие поля попадут в отдельный список «уточнить».
